 # Cassie Launcher

 A powerfull but lightweight fortnite launcher written in C#

<p align="center">
  <img src="./image.png" />
</p>

## Features

- Multiple account support
- Download, Update and launch games from the launcher
- Auto claim rewards at the end of a mission
- Friend management
- Item shop
- Ghost equip cosmetics in the lobby
- Backpack and Storage management
- Custom plugin support

## Features In Development 

> - Homebase Visualizer: Interactive homebase data viewer paired with a live map.
> - Player Lookup: In-depth player analytics, profile lookup, and statistics tracking.
> - Code Redemption: Native in-app promo code redemption tool.
> - Advanced Security: Hardened encryption standards for locally cached credentials.
> - UI Overhaul: Major interface refresh for modernized navigation and layout.
